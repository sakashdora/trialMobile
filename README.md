# Azure mobile showcase

A responsive, frontend-only brand and shopping concept. Run `npm run dev` and open http://127.0.0.1:4173. Run `npm run check` to check application JavaScript syntax. Deployable static files are in `dist/`.

Includes CSS-rendered dimensional phones, finish selection, responsive navigation, model comparison, configurable products, a browser-local preview bag, FAQ and accessible native dialogs. Reduced motion is supported. Google Fonts are optional; system fallbacks are provided.

Names, specifications and prices are illustrative and marked in the interface. No payment, order, account, analytics or subscription endpoint is connected. Bag selections are stored locally. Before backend work, confirm the real catalog, currency, inventory, shipping regions, warranty and returns policy, then choose payments and order management integrations. Replace concept claims with approved product content before a public store launch.
