# Active assets

The active storefront now implements the approved ten-phone visual design. See
[Approved design assets and prompts](approved-design-assets.md) for the four local render assets,
their generation prompts and their usage.

`public/assets/collection-v3/` contains the active hero, ten-phone contact sheet,
four-accessory contact sheet and camera detail. These were generated with the built-in image tool
after the user approved the image-led design. The footer labels them as concept renders.

The earlier real reference photographs in `public/assets/photography/` are retained but no longer
loaded by the active page. Old generated products and videos remain archived outside the site
at `D:/AZURE/artifacts/removed-generated-assets-20261113`.
